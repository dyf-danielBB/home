# DLC 空间起始页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立受独立认证网关保护的 Homepage 起始页，预置 DLC 服务入口并应用极光深海主题。

**Architecture:** 使用 `ghcr.io/gethomepage/homepage:v1.13.1`，配置文件只读挂载；不直接挂载 Docker Socket。原始 3103 端口只绑定 NAS 本机，用户通过 3105 的 Caddy Basic Auth 访问。

**Tech Stack:** Homepage v1.13.1、YAML、Caddy、Docker Compose、CSS。

## Global Constraints

- 起始页固定版本 `v1.13.1`，必须设置 `HOMEPAGE_ALLOWED_HOSTS=nav.dailecheng.xyz`。
- 不允许将 `HOMEPAGE_ALLOWED_HOSTS` 设置为 `*`。
- 起始页只能在认证后访问。

---

**Files:**
- Create: `apps/nav/compose.yml`
- Create: `apps/nav/config/settings.yaml`
- Create: `apps/nav/config/services.yaml`
- Create: `apps/nav/config/widgets.yaml`
- Create: `apps/nav/config/bookmarks.yaml`
- Create: `apps/nav/env.example`
- Create: `tests/nav/config.test.mjs`

**Interfaces:**
- Produces: `dlc-nav:3000`，仅本机 `${NAV_PORT:-3103}`。
- Produces: 六个入口：主页、博客、网盘、网址集、今日热榜、音乐站。

- [ ] **Step 1: 写失败测试**

- [ ] **Step 2: 运行并确认失败**

Run: `node --test tests/nav/config.test.mjs`
Expected: FAIL，提示配置文件不存在。

- [ ] **Step 3: 实现配置**

`settings.yaml` 使用中文、深色主题和卡片布局；`widgets.yaml` 配置搜索、日期时间，以及从 `HOMEPAGE_VAR_LATITUDE`/`HOMEPAGE_VAR_LONGITUDE` 读取坐标的天气组件；`env.example` 默认使用上海坐标 `31.2304,121.4737` 且允许 NAS 部署时覆盖；`services.yaml` 按“DLC 空间”分组写入六个入口；`bookmarks.yaml` 保持空数组，避免重复；Compose 只读挂载配置并配置健康检查。

- [ ] **Step 4: 验证**

Run: `node --test tests/nav/config.test.mjs && docker compose --env-file apps/nav/env.example -f apps/nav/compose.yml config --quiet`
Expected: PASS。
