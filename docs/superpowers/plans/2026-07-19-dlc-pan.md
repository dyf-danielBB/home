# DLC 空间网盘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 部署固定版本 OpenList，并通过可回退的外部前端覆盖实现 DLC 网盘主题与登录保护。

**Architecture:** 使用 `openlistteam/openlist:v4.2.3`，仅挂载独立数据目录。主题通过 OpenList 支持的 `dist_dir` 外部前端机制或后台自定义头部/CSS 注入，不修改数据库，不移除上游版权标识。

**Tech Stack:** OpenList v4.2.3、Docker Compose、CSS、Node.js 契约测试。

## Global Constraints

- OpenList 固定版本 `v4.2.3`，默认端口 `3102`。
- `site_url` 固定为 `https://pan.dailecheng.xyz`，末尾不得有 `/`。
- 网盘必须登录；不得创建示例文件，不得提交 `data/config.json` 或数据库。

- Create: `apps/pan/env.example`
- Create: `apps/pan/README.md`

**Interfaces:**
- Produces: `dlc-pan:5244`，NAS 外部 `${PAN_PORT:-3102}`。
- Consumes: `${DLC_DATA_ROOT}/pan`、`DLC_PUID`、`DLC_PGID`。

- [ ] **Step 2: 运行并确认失败**

Expected: FAIL，提示 `apps/pan/compose.yml` 不存在。

- [ ] **Step 3: 实现 Compose 和首次启动说明**

Compose 设置 `PUID`、`PGID`、`UMASK=022`、日志轮换和 `restart: unless-stopped`。README 写明创建数据目录、首次启动、使用 `docker exec dlc-pan openlist admin set NEW_PASSWORD` 设置管理员密码、在后台设置 `site_url`、关闭匿名写入和添加存储的步骤。
