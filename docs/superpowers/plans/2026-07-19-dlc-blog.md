# DLC 空间博客 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于固定提交的 Miniblog 建立可独立构建、公开访问并符合极光深海主题的 DLC 博客。

**Architecture:** 将 Miniblog `3d840c3ecde0dcfb91bca14a95d7cb93714ef9d9` 以无嵌套 `.git` 的源码快照放入 `apps/blog`，保留 Astro/Markdown/RSS 能力；使用多阶段 Docker 构建生成静态站点。

**Tech Stack:** Astro、Markdown、pnpm、nginx Alpine、Docker Compose。

## Global Constraints

- 上游固定为 `nicholasdly/miniblog@3d840c3ecde0dcfb91bca14a95d7cb93714ef9d9`。
- 品牌、颜色、字体、动效和密钥约束遵循设计文档。
- 默认外部端口 `3101`，公开访问。
