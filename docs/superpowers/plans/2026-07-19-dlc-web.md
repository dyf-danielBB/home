# DLC 空间网址集 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于固定版本 OneNav 建立公开网址集、登录后台、初始分类和 DLC 主题。

**Architecture:** 将 OneNav `v1.2.4` 源码快照放入 `apps/web/src`，使用固定 PHP-Apache 镜像运行，数据库目录独立持久化。DLC 主题作为新的 OneNav 主题目录，避免改动核心控制器。

**Tech Stack:** OneNav v1.2.4、PHP 8.2 Apache、SQLite、Docker Compose、CSS/PHP 模板。

## Global Constraints

- 上游固定为 `helloxz/onenav@v1.2.4`（提交 `011299a9fe4635e8be48cf66cb0833bae07e8c69`）。
- 前台公开，后台必须登录；默认外部端口 `3104`。
- 只预置“个人站点、常用工具、开发资源”；后两个分类不编造网址。
