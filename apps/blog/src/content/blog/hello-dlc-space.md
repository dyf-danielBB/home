# 你好，DLC 空间

这是 DLC 博客的第一声问候。我会在这里记录实验、复盘和小小的发现。

## 你会在这里读到

- 自托管服务的搭建与维护
- 简洁可用的界面实践
- 个人项目的过程记录

> 把复杂留在工具里，把清晰留给读者。

这个站点由 [Astro](https://astro.build/) 生成。文章保留为简单的 `.md` 文件，因此无论是迁移还是归档都很直接。

## 一小段代码

比如，极光色可以被写成一个可复用的 CSS 变量：

```css
:root {
  --dlc-primary: #55d6be;
}

a {
  color: var(--dlc-primary);
}
```

接下来，让这个小空间慢慢长大。
